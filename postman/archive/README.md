# Archived Postman collections

These files are **not** for day-to-day use. They are kept as merge inputs and historical snapshots.

**Use instead:** `../Help-PR-All-APIs.postman_collection.json` (import that in Postman).

To rebuild the unified collection after editing a source file here:

```bash
node postman/merge-all-collections.mjs
```

Do not add new API requests only to archived files without re-running the merge script.
